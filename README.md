# Minigame 1
## Devlog
Scene is just like a theater stage, object are the actor, they follow the scripts, and move and act as they where asked, Components are the personality or the skills actors has, just like the object has a skill of jump or can hurt the player. Withoutthe components, the actor will have no responce to any action.
